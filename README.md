## 🌟 Overview

**PARADOX ARENA** is a high-performance, cinematic college techno-cultural festival website engineered with semantic HTML5, modern CSS3, and Vanilla JavaScript.

Designed with a dark futuristic editorial aesthetic inspired by high-end international music festivals and futuristic technology conferences, the platform delivers fluid interactions, real-time telemetry, and reactive cybernetic shaders.

---

## ⚡ Tech Stack & Architecture

- **Semantic Markup:** HTML5 with ARIA accessibility roles and landmark structure.
- **Styling Architecture:** Pure CSS3 design token system, CSS Grid, Flexbox, custom properties, and full responsive scaling from 320px to 1920px+.
- **Smooth Scrolling Engine:** [Lenis](https://github.com/darkroomengineering/lenis) synchronized with [GSAP ScrollTrigger](https://greensock.com/scrolltrigger/) with zero-lag physics (`0.65s` duration).
- **Interactive Shaders & Visuals:**
  - **Digital Rain Curtain:** Custom WebGL2 shader (`js/digital-rain.js`) with pointer proximity parting, wind sway physics, and lightning tap effects.
  - **Flower Border:** Procedural Three.js fan shader (`js/flower-border.js`) rendered via full-screen quad.
  - **Originkit Scramble Text:** Glitch character reveal (`js/scramble.js`) with cubic-bezier easing, wave cursor decoding, and interactive mouse hover diffusion waves.
- **Micro-Interactions & Components:**
  - Dynamic HUD Festival Countdown Telemetry Timer.
  - Interactive Event Discovery Matrix with 3D perspective card tilt.
  - Live Holographic Admission Pass Studio with real-time pass generation.
  - Cyber Terminal Preloader with progress simulation.
  - Ambient Web Audio Synthesizer toggle.
  - Lucide Vector Icons.

## 🚀 Running Locally

1. Clone or download this repository.
2. Serve using any local HTTP static server:
   ```bash
   # Python 3
   python -m http.server 8080
   ```
3. Open `http://localhost:8080` in any modern web browser.
